Git Check

Descubra quem quem você segue, mas não te segue de volta.

⚠️ Atenção: A API pública do GitHub permite 60 requisições por hora, como cada requisição retorna no máximo 100 seguidores, perfis grandes precisam de várias requisições e podem atingir o limite rapidamente.

FAQ

Perguntas Frequentes

O Git Check invade minha conta do GitHub?

Não. Se invadisse contas, eu estaria trabalhando na Microsoft e não mantendo projeto open source 😂, o Git Check usa apenas dados públicos da API do GitHub.

Preciso informar meu token ou senha?

Não. E se algum projeto pedir isso, feche a aba. O Git Check não coleta tokens, senhas ou qualquer dado sensível.

O Git Check dá unfollow automático?

Infelizmente não. Se desse, eu já estaria banido do GitHub. Aqui a ideia é mostrar a verdade, passar a tesoura é por sua conta ✂️

Por que minha lista está vazia?

Existem três possibilidades:
1️⃣ Você é muito amado 🥰
2️⃣ Você segue pouca gente
3️⃣ Você ainda não foi traído (aproveite enquanto dura)

Posso usar para stalkear outras pessoas?

Tecnicamente sim. 👀 Moralmente... também. 💀 Mas lembre-se: com grandes poderes vêm grandes unfollows 🕷️.

Isso funciona para contas grandes?

Funciona até o limite da API pública do GitHub, ou seja, 60 requisições por hora, cada requisição verifica até 100 usuários. Se você segue e tem muitos seguidores, pode ser que precise esperar um pouco ou dar "unfollow" manualmente.

Preciso usar Token do GitHub?

Não. O Git Check funciona 100% sem token, usando apenas a API pública do GitHub. 👉 Isso significa: Até 60 requisições por hora, pode falhar em perfis gigantes (celebridades do código 👀)

E se eu quiser usar um Token?

Aí o poder é seu 😈, você pode rodar o projeto localmente e adicionar seu próprio token no código para aumentar o limite para até 5.000 requisições por hora. ⚠️ Importante: Nunca use token em projeto público ou em deploy online, Token é igual escova de dente, pessoal e intransferível.
